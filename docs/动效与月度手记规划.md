# 3.1 · 纸页式动态阅读

日期：2026-10-16。沿用已获认可的暖纸色、陶土色、青灰色、文档式层级与四页信息架构。本轮是阅读与交互升级，不替换现有产品风格。

## 创意方向

把每个月视作手记的一页。月份纸卡、分段阅读与收支数据组成一个轻巧的开篇；滚动像继续读一页账本，操作像在纸面上留下一笔。核心金额即时显示，图表仍准确表达原始数据。

| 层级 | 设计 | 规则 |
| --- | --- | --- |
| 首屏 | 月份纸卡、错层纸边、月份编号、手记入口；标题与摘要分层入场 | 单段 450–750ms，纸卡细线含延迟 810ms 内结束；操作即时可用 |
| 滚动 | 阅读进度细线、纸卡轻微景深、内容段落首次进入视口时展开 | 位移 8–16px；无滚动劫持，无固定播放区 |
| 导航 | 桌面与手机选中背景平滑移动；页面内容短暂过渡 | 路由和焦点先更新，动画不承担业务状态 |
| 数据 | 收支摘要轻微位移展开；预算条从左展开，分类行及日期悬停反馈 | 文字始终不透明，不用滚动数字制造中间假金额，不扭曲坐标 |
| 微交互 | 纸卡轻倾、箭头前移、按钮按压、文件选择与校验反馈 | 触摸有按压反馈；键盘具有等价功能 |
| 动效偏好 | 系统 reduced-motion + 应用减少动态效果开关 | 随时切换立即取消装饰动画，内容保持可见 |

实现采用 CSS 过渡、Web Animations API、IntersectionObserver 和共享 requestAnimationFrame 更新。只使用 transform / opacity 做位置与显隐变化；不新增大型动画依赖。CSS 保留完整默认状态，动画只作渐进增强。段落每次视图挂载只入场一次，离屏内容不循环播放；一处被动滚动监听更新阅读进度，纸卡景深超过 380px 滚动距离后保持固定值，手机关闭景深。卸载清理观察器、监听器与动画。

## 本轮落实的既有规划

1. **月度手记**：按月编辑、服务端保存，月报打印包含手记；支持最多 800 字，写操作沿用管理令牌。
2. **月结状态**：自动判断 / 仍在记录 / 已完成月结。状态在页面可见，实际参与自然日和环比口径；不能仅改变徽标。历史月份可明确标记未完整。
3. **导入差异预览**：区分新增、实际变更、内容相同；展示同 ID 的字段前后值。确认前不写入，确认时重新校验。批次撤销及崩溃级事务继续保留在后续路线。

## 验收标准

- 保留已有 40 项浏览器用例与后端回归；新增月度保存、月结统计、导入差异的功能测试。
- Chrome DevTools MCP 检查 1440 / 1024 / 768 / 390 / 375 的四页布局；实际滚动，查看入场、悬停、切月和弹窗过程，不只看最终截图。
- 对默认 / 减少动态效果两种模式做截图、动画状态与控制台检查；用动态中间帧和后续帧证明行为。
- 核验手记保存、刷新、打印内容；测试数据结束还原，原始账单不修改。
- 最终使用 frontend-design、ui-ux-pro-max 搜索建议与 web-design-guidelines 审查。优先遵循用户已认可的风格，具体动画强度以实页调整。

## 本轮范围之外

公网域名 / HTTPS / 家庭认证部署、分类编辑、批次撤销、原子数据版本、整数分迁移和实机 Safari 验证继续列为后续工作。本轮计划已实现，验证范围与限制见 [3.1 验收记录](验收记录-3.1.md)。
