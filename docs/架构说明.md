# Ledger Atlas 3 · 架构与数据契约

## 运行结构

```text
浏览器 React / TypeScript / shadcn/ui / Recharts
  ├─ Vite 开发端口 5173 → /api 代理 → 8000
  └─ 生产：FastAPI 8000 同时提供 / 与 /assets
                       ↓
FastAPI 查询、导入、预算接口
  ├─ analytics.py：从标准主表计算统计，前端不重复定义统计口径
  ├─ imports.py → ingest.py：预览校验、按 ID 合并、生成快照
  └─ preferences.py：共享月度预算
                       ↓
data/origin → processed_atlas CSV + SQLite + 清单 → archive_atlas 月度镜像
data/settings.json：预算
```

生产前端必须 `npm run build`。`app.py` 导出 ASGI 应用，`server.py` 是本地启动入口。数据查询当前以标准 CSV 加载至 pandas 为主，SQLite 是可互操作的持久镜像，不声称所有查询都经过数据库。

## 前端分层

- `src/App.tsx`：布局、月份、路由、全局浮层。`lib/location.ts` 维护 URL 与后退历史。
- `pages/`：总览、分析、账单、数据管理；`React.lazy` 按需加载。
- `components/ui/`：shadcn CLI 生成的 Radix 组件，经本地样式与中文可访问名称调整。
- `components/charts.tsx`：Recharts 图表、工具提示、数据表；在实际容器测量后绘制，避免手机使用桌面预估尺寸。
- `components/dialogs.tsx`：预算、导入预览 / 提交、账单详情。令牌仅保存在当前浮层内存中。
- `lib/api.ts` / `types.ts`：请求、错误、接口类型；TanStack Query 管理缓存、请求取消与变更后刷新。
- `index.css`：统一设计变量、页面布局、响应式、焦点、减少动画和打印样式。

## 数据契约和合并

必需来源列：`ID、时间、分类、类型、金额`。可选列包括 `账本、二级分类、币种、账户1、账户2、备注、已报销、手续费、优惠券、记账者、账单标记、标签、账单图片、关联账单`；派生 `日期、月份、年份`。

ID 按字符串读取，保留前导零。文件内同 ID 取最后一行；跨文件按来源顺序取最后一条，再按交易时间排序。手工来源按文件名顺序，界面确认上传的 `upload_` 文件优先，并按微秒时间戳排序。因此更正交易日期为更早时间也不会被旧记录覆盖。

预览只读取，不落盘；确认时重新校验。上传支持 CSV / XLSX / XLS，限制 10 MB。当前只接受人民币收入与支出；不将转账直接加入生活费统计。分类仍使用 `config.py` 中的固定映射，未知分类会标准化为「其它 / 未分类」，分类自定义属于下一阶段。

## 查询接口

| 方法与路径 | 用途 |
| --- | --- |
| GET `/api/health` | 版本、记录数、写入是否需要管理令牌 |
| GET `/api/summary?month=YYYY-MM` | 汇总、趋势、分类、日度、近期记录、观察、预算、覆盖范围 |
| GET `/api/patterns?month=YYYY-MM` | 二级分类和消费节律 |
| GET `/api/transactions?month=YYYY-MM` | 月份全量明细；前端筛选后按 15 条分页 |
| GET `/api/data-room` | 文件清单、哈希、字段与重复 ID |
| POST `/api/import/preview` | multipart 文件预览、无效行、新增与已有 ID 数 |
| POST `/api/import` | 校验后保存来源、重建、刷新缓存 |
| PUT `/api/budgets/{month}` | JSON `amount`；正数为预算，null 为取消 |

无效月份查询回落到数据中的最近月份，响应 `month` 表示实际选择。未设置管理令牌时允许本地写入；配置 `LEDGER_ADMIN_TOKEN` 后，上述三个写入 / 预览接口要求 `X-Admin-Token`。阅读认证应由部署入口提供。

## 统计定义

金额按来源收支类型统计为正数，结余 = 收入 − 支出；不是银行卡实际余额。最新月份最后记账日早于月末时显示部分月份，日均按月初至该日的自然日计算，环比比较上一自然月相同日区间。缺少上月记录或上月支出为零时返回 null。历史月份按完整自然月展示，这只是当前推断规则，并不证明没有漏记。

每日缺少记录时图表补零，只表示该日没有支出记录。月历超过最新收录日的格子不可点击，明确标记未收录。年度图表按当前选择年份过滤。所有分析只描述已经导入的数据。

## 持久化与并发边界

预算先写临时文件再替换。导入和读取通过同一进程锁协调；重建失败会移除本次新来源并尝试恢复旧快照。SQLite 连接明确关闭。该机制适用于单进程家庭应用；多文件快照尚未实现崩溃级原子事务，不配置多个 worker。生产备份应覆盖整个 `data/`，不能只复制 SQLite。

`data/origin` 是事实来源；直接手工放入文件后需要运行重建命令。旧月度归档属于派生镜像，主查询始终以主表为准。严格原子版本、批次撤销、整数分金额模型见总体规划。
