# v1.0 架构说明

## 目标

v1.0 将项目从“单页账本看板”升级为“个人账本数据工作台”。Streamlit 继续作为部署和交互层，其他部分按数据、分析、UI 组件和脚本分层。

## 分层

- `app.py`: Streamlit 薄入口，仅导入 `src.ui_app`。
- `src/ui_app.py`: 页面编排，负责登录、侧边栏、月份选择和五个工作区。
- `src/styles.py`: v1.0 视觉系统，采用浅色纸面、石墨侧栏、铜色和蓝绿色强调。
- `src/ui_components.py`: 页面组件和格式化工具。
- `src/data_service.py`: UI 可调用的数据服务门面，集中管理路径、导入、重建和状态检查。
- `src/data_pipeline.py`: CSV 读取、规范化、归档、主库合并和从 `data/origin` 全量重建。
- `src/sqlite_store.py`: SQLite 主表读写、完整替换和 CSV 快照导出。
- `src/data_quality.py`: 主表、存储一致性和质量告警。
- `src/analytics.py`: 现金流、分类动量、预算压力、节律、异常和洞察。

## 数据流

1. 原始账单 CSV 放入 `data/origin/`。
2. `normalize_records()` 补齐标准字段、修复时间/金额/类别/币种。
3. 日常导入走 `import_csv_file()` 或 `import_csv_bytes()`，按 ID 合并覆盖。
4. 全量修复走 `rebuild_from_origin()`，从所有 origin CSV 合并去重后替换 SQLite 和 CSV 镜像。
5. SQLite 是主数据源，`data/processed/ledger_master.csv` 是快照，`data/archive/YYYY-MM.csv` 是月度镜像。

## UI 工作区

- 总览：KPI、现金流、累计结余和自动摘要。
- 结构：一级分类、分类动量和二级分类穿透。
- 预算与异常：历史月均预算压力、下月预算建议和大额异常。
- 节律：日度累计、星期画像和跨月分类占比。
- 数据室：数据质量、存储一致性、本月明细。
