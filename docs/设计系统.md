# Ledger Atlas 3 · 设计系统

## 方向与决策

使用 frontend-design 与 UI/UX Pro Max 的 Minimalism / Swiss Style 规则。借鉴 Notion 的文档层级与 Claude 的暖纸色，按中文账本阅读习惯设计。工具给出的营销页 Hero/CTA 模板不适用于账本，不采用。核心原则是 30 秒读懂本月，2 次操作追到明细。

- 背景 `#FAF9F6`，侧栏 `#F1F0EA`，正文 `#292824`，次要文字 `#625F57`。
- 陶土色 `#AD563D` 用于支出和主操作；青灰色 `#496F68` 表示收入。颜色之外始终有文字与正负号。
- 标题 30–36px，主要正文 13–14px，说明 12px；英文眉题和日历金额使用 10px 辅助微文案。金额使用本地托管 DM Sans 和等宽数字；中文标题采用正常字形的宋体族，不做斜体拼接。
- 内容最大宽度 1280px；桌面侧栏 220px；主内容边距 32–48px。手机用四项底部导航，主要入口约 44px 触控区域；输入字号 16px 避免移动浏览器自动放大。
- 细边界、小圆角、不用通用卡片堆砌；浮层和月份纸卡使用轻阴影。图表线宽 2–3px，真实 tooltip，明确单位和时间口径。
- 状态反馈 140–240ms，章节动作 450–750ms；遵循 reduced-motion。数据更新保留布局，加载与错误明确可见。

## 组件与交互

真实 shadcn/ui：Button、Select、Dialog、Tabs、Input、Textarea、Tooltip、DropdownMenu、Sheet、Sonner。使用组件内建的键盘导航、焦点锁定和 Escape 行为。

四个页面：月度总览、消费分析、账单明细、数据管理。月份、页面、筛选写入 URL。分类和高消费日可追到筛选后的账单；明细支持搜索、分类/收支筛选、排序、分页、详情、CSV 导出。预算服务端保存。导入先预览校验，再提交；失败不污染来源文件。

## 3.1 动态语言

沿用用户认可的布局和颜色。Hero 是每月手记的开篇：右侧错层纸卡展示月份，点击直接编辑手记和月结；手机变成紧凑横条。摘要继续位于首屏，不加入占满屏幕的宣传区。

- 纸卡用小角度入场和鼠标倾斜表现层次；滚动景深最多约 21px / 3°，手机禁用景深，无滚动接管。
- 正文首次进入视口轻移 14px，最多 130ms 错峰。正文、金额、按钮文字全程不透明，避免动画中途降低对比度；只对装饰花形使用淡入。
- 导航选中背景滑动，按钮按压缩放至 0.97，账单箭头和日历有短促反馈；金额直接显示真实值。
- 右上角动效开关保存本机偏好；系统减少动态效果优先，立即取消 Web Animations 与 CSS 动画。此时所有信息和功能完整可用。
- 手记使用纸页正文，保留换行、长文本自动折行。触摸设备打开弹窗先聚焦标题，用户点击输入后再呼出键盘；退出草稿有继续 / 放弃，返回编辑恢复输入焦点。

动效规范、交付范围见 [本轮规划](动效与月度手记规划.md)。这套层次适用于已有账本页面，后续增加组件继续复用统一变量与偏好。

## 真实口径

不显示无依据的健康评分。不把最新文件的月内数据视为完整月份。显示最后记账日期；最新月份比较使用截至同日的上月记录，并明确观察范围；没有记录不等于没有消费。
