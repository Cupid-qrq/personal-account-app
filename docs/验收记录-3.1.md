## 真实动作与视觉迭代

动效检查使用真实 Chrome 的 CSS / Web Animations 对象、指针事件及页面滚动，不以截图文件存在作为通过条件。

1. 首屏在 80ms、360ms 及结束状态采样真实 CSS 动画，保存三帧。80ms 时纸卡尚有旋转 / 位移、文字不透明；动画结束后回到静止状态。采样时主动暂停时间轴，因此这些是关键帧证据，不是实时视频或帧率测量。
2. 鼠标经过月份纸卡触发轻倾，移开恢复；滚至页尾验证阅读进度、纸卡景深和段落入场。手机使用紧凑纸卡，关闭滚动景深。
3. 手动减少动态效果立即取消动画，刷新后保留；另启 Chrome 系统减少动态效果实例，验证首次渲染、滚动和手机布局均不播放动画。
4. 查看桌面与手机画面后，保留原有文档层级。月卡留出开篇空间，收支摘要仍在首屏；手机手记弹窗不出屏。
5. 最终复核发现正文淡入会让灰色说明在动画中途低于对比度要求。改为全文字持续不透明，只做位移，装饰花形保留淡入；重新执行全部常规回归，并增加中间帧 axe 检查。
6. 手机打开手记改为聚焦标题，避免直接激活输入法；放弃确认中的“继续编辑”恢复输入焦点。通过实际 activeElement 与截图验证，键盘行为仍待真实手机补验。

## 新增业务验收

- 月度手记：填写多行说明 → 保存 → 刷新 → 总览正文与打印模板内容一致；退出草稿可继续 / 放弃。测试结束恢复原来的手记和状态值，更新时间相应更新。
- 月结：确认完成后，十月的 observed_days 从 9 变为 31，分析日序列同步改变；可以改回自动判断。后端额外检查历史月份仍在记录、不可比上月隐藏百分比，以及上月覆盖已足够但区间末尾恰好没有消费的情况。
- 导入：同一 Excel 预览得到新增 0、变更 0、相同 387；构造更正 CSV 能看到金额 75.00 → 80.00 及其他变化字段。预览之后真实十月支出仍为 744，未点击确认导入。
- 设置：手记写入保留预算区段；管理令牌保护新接口；超过 800 字符、非法状态及没有账单的月份被拒绝。预算不足 0.01 元不再接受并舍入为零。

实际导入 / 重复更正 / 写入失败的回归在临时目录完成。生产账本只进行了可还原的预算、手记设置测试；八月已有预算 4000 保留，十月预算恢复未设置。
