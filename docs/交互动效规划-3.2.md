# 3.2 · 可重复交互与滚动编排

日期：2026-10-16。保持暖纸色、陶土色、青灰色及四页布局。本轮聚焦持续可用的交互与更明确的滚动联动，并移除装饰性文案。

## 动效分工

| 类型 | 落点 | 行为 |
| --- | --- | --- |
| Scroll-linked | 首页月份纸卡 | 随 0–260px 滚动连续翻转、错层纸张展开；向上滚动原路收回，停滚即停 |
| 3D Tilt + Spring | 月份纸卡 | 每次指针进入都可响应，约 ±8°，离开弹性归位；稳定外层接收指针，内层负责形变 |
| Spotlight + Animated Border | 月份纸卡 | 局部暖光跟随指针，边线随悬停亮起，不增加全屏光效 |
| Magnetic Button | 首页“月度手记”操作 | 内容向光标靠近最多 5px，按钮原始点击区域固定；离开弹性归位 |
| Hover Lift + Icon Nudge | 账单行、分类入口 | 悬停轻抬、图标前移；键盘焦点提供同等可见反馈 |
| Animated Underline | 正文文字链接 | 下划线从左展开，移开收回 |
| Staggered Animation | 近期账单列表 | 按顺序短距离入场，间隔 40ms，金额保持真实值 |
| Skeleton Shimmer | 加载占位 | 轻扫光播放三次后静止，加载提示继续保留 |

入场、滚动、悬停分别占用独立 DOM 层，避免同时改写同一个 transform。滚动优先采用 CSS ScrollTimeline；不支持时由共享 rAF 监听提供同样的纸卡进度。指针弹簧只在运动期间运行，停止后不占用连续帧。手机保留适度滚动展开、按压与焦点反馈，禁用鼠标专属倾斜 / 磁吸。系统或应用减少动态效果立即停止装饰运动。

## 文案清理

删除纸卡“生活记录中”、页尾和近期账单的“每一笔，都有生活的注脚”、洞察尾部的生活格言、侧栏标语。标题、空状态与辅助文字改为简洁的任务说明；保留覆盖范围、统计口径、错误与保存状态等必要信息。

## 验收

真实 Chrome DevTools MCP 检查：至少五次进入 / 移动 / 离开；打开关闭手记后再次悬停；换月和切页返回后再次悬停；检查最终 transform 而非只检查 CSS 变量。滚动在起点 / 中段 / 终点 / 返回起点采样，停留后不得自行变化。磁吸必须归位且可键盘打开手记。检查默认、系统和手动减少动态效果，四页五种宽度、文字溢出、控制台与 axe；最后用 web-design-guidelines 复核并保存截图。相关业务保持既有回归。

实现结果见本轮验收记录；不把一次入场播放或 DOM 属性变化视为可重复交互验收。
