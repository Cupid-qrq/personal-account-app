## 视觉验证与迭代

实际打开截图逐页检查，修改后重新截图，不只依赖构建或 DOM 宽度判断。

1. 第一轮提高正文可读性，手机收支分为清楚的主金额和两项次指标；圆环及分类在手机改为单列，避免挤压。
2. axe 检出部分浅色文字对比不足、图表 Tabs 的 ARIA 关联缺失；已调整文字颜色并补全关系。
3. 手机首次渲染截图发现图表使用预估桌面尺寸，导致曲线空白或圆环错位；移除预估尺寸，检查实际 SVG 几何后截图。
4. 手机日历未收录标签出现断字；改为淡色未启用日期，并保留完整读屏说明与脚注。
5. 浮层截图等待有限动画结束，再验证详情抽屉 / 导入弹窗边界，避免将动画中间帧作为最终画面。
6. 断网检查发现 React Query 暂停请求、页面停留在同步状态；本地账本查询改为始终尝试请求，失败显示可操作的重试提示。
7. 对手机长页面中的图表额外滚动至可见区域，检查完整柱图、坐标与数值，并保存 `mobile-chart-viewport.png`；最终画面不只依赖整页截图。

截图与证据在 `output/qa/`：`overview-1440.png`、`overview-375.png`、`analysis-*`、`ledger-*`、`data-*`、`detail-desktop.png`、`import-mobile.png`、`import-preview.png`、`chart-tooltip.png`、`budget-saved.png`。`devtools-transcript.jsonl` 保留实际 MCP 调用；`performance-desktop.json.gz` 保留性能追踪。个人数据截图不上传 Git。
