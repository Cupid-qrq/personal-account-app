## 本轮实际交互证据

- **重复倾斜**：在稳定命中区域加入临时透明定位点，让 Chrome MCP 的 `hover` 真实移动鼠标；连续五轮左上 → 右下 → 离开，检查最终 CSS matrix3d 确实改变并恢复。不是通过脚本分发 PointerEvent 验收。定位点随后移除。
- **生命周期**：打开 / 关闭手记、键盘切换到九月、进入消费分析再返回总览，各自再次进行真实鼠标往返；均可重新倾斜。
- **滚动联动**：确认运行中的 timeline 类型为 `ScrollTimeline`；在 0 / 100 / 240 / 0px 采样，纸张矩阵连续变化，停在 240px 后保持原值，回到 0px 后与起始矩阵相同。额外禁用原生动画，验证进度变量的 fallback 路径也随滚动变化和复位。
- **磁吸**：三轮指针靠近 / 离开，内部内容偏移并归零；鼠标打开后关闭，再按 Enter 能重新打开手记。按钮可点击区域保持固定。
- **其他反馈**：实际查看账单行上浮、链接下划线、指针暖光与高亮边线；近期账单具有依次递增的入场延迟，金额未变。
- **减少动态效果**：活动中的弹簧立即停止，纸卡和滚动层恢复静态；重新开启后能再次悬停。系统偏好下初次加载和手机页无装饰动画。
- **手机**：375px 页面没有横向溢出；触摸模式不触发鼠标倾斜或暖光。月度选择、手记与导出三项操作能同排显示；手记浮层及页面内容经过截图检查。

3.1 的隔离合成事件检查可以触发变量变化，不能据此排除用户报告的交互观感问题。本轮通过分层重写、增加幅度和真实鼠标重复验收解决，不声称已从原版本证明唯一根因。

## 视觉迭代与审查

1. 首页磁吸入口受到旧 `.page-actions` 透明背景规则影响，首轮截图显示浅色文字；已明确按钮主色和悬停色，再次检查对比度。
2. 新增磁吸键盘用例发现关闭手记后焦点没有回到入口；补充 `onCloseAutoFocus`，通过实际 Enter 再打开验证。
3. 暖光的纹理画布大于纸卡，虽被裁切，但严格子元素边界检查仍报告越界；改为卡片内的有界容器和内部伪元素纹理，1024 / 768px 复测通过。
4. 清理“生活记录中”、页尾和近期账单的“每一笔，都有生活的注脚”、洞察末尾格言、侧栏口号；保留真实月结状态、覆盖说明和错误提示。
